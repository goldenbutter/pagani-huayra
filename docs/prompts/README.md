# Generation prompts

For future car images or videos, start with [Vehicle generation master v5](vehicle-generation-master-v5.md). It explicitly fixes cockpit driving side across angles, colours, opening and exploded assembly, with interior checks before accepting reference images and video clips.

The `generation-prompts*.json`, `flow-v2/image-generation-prompts.json`, Flow clip prompts, Kling submitted prompts and `render-ledger.json` document earlier work. They do not contain the complete v5 cockpit lock. Preserve them as generation history; do not reuse them as complete future prompts without the configured v5 identity lock and reference checks.

This revision changes future guidance only. Existing videos, images and website assets are preserved.
