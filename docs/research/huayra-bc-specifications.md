# Production-car specification review

Checked 29 October 2026 for the Huayra BC Coupé. The active data is in `data/carData.ts`; the page and engine callout use the same reviewed figures.

Primary source: https://www.pagani.com/huayra-bc/
Dry-weight qualifier: https://www.paganiofchicago.com/models/huayra-bc/

The manufacturer's table specifies 764 CV, not the previous brief's 745 HP. Preserve CV as metric horsepower rather than silently relabelling it. The engine is twin-turbo, not naturally aspirated. The gearbox is an Xtrac seven-speed automated manual, not a dual-clutch unit. The official table labels 1,218 kg simply as weight; the dealer source identifies dry weight. Do not present this as kerb weight.

Do not mix this Coupé with the Roadster BC or Huayra R. Acceleration, top speed and a current selling price were excluded because they were not verified in the chosen manufacturer source. The generated livery, exploded parts and mechanical arrangement remain creative visualisations.
