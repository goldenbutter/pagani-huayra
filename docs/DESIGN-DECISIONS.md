# Approved direction

- Three cars side by side with a small overlap on desktop; stacked on mobile.
- Selecting a car changes the website's accent palette and all matching editorial imagery, then enters its cinematic scroll experience.
- White backgrounds throughout. Red accents for Rosso, blue for Bianco, emerald with restrained gold for Verde.
- This is an iBithun portfolio concept and sales demonstration for web-design services. It is not an official Pagani project and has no real dealership or car-sale inquiry flow.
- Follow the ENERGITIX credit pattern: portfolio.ibithun.com, iBithun creator credit and a clear concept disclosure. Inquiry links to bithun@ibithun.com for website projects.
- Create 240 frames per color if feasible. Completed through 24 → 30fps motion-compensated interpolation of the supplied eight-second films.
- Preserve source originals outside the public web directory. Group web derivatives by media type and color.
- Use the requested Next.js App Router, TypeScript, Tailwind v4, Framer Motion, Lenis and Canvas stack, with Orbitron/Rajdhani fonts.
- Intended future hostname: pagani.ibithun.com. No deployment or GitHub publication was requested in this implementation step.

## Exploded-view extension

- Add an exploded fifth chapter after the original rotation, door and engine sequence, for all three colors.
- Keep the original film's 500vh of scroll travel inside a 900vh section; remaining travel covers the transition and assembly separation.
- Use generated transparent artwork split into eight independently animated modules on Canvas. This provides reversible scroll motion without requiring a new video or a 3D model.
- Retain matching white studio presentation, selected palette and current scroll position across color switches.
- Present the assembly as an artistic study, not a mechanically accurate or serviceable CAD representation.
- Save originals, browser derivatives and exact generation prompts in their existing dedicated folders.
